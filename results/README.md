# Numerical Results

The result files report objective values for 10 runs.

## Ten-run result files

| Field | Description |
|---|---|
| `family` | Instance family |
| `instance` | Instance identifier (e.g., `C101-20`) |
| `customer_count` | Number of customers |
| `algorithm` | Algorithm name used in the manuscript |
| `run_id` | Run identifier, from 1 to 10 |
| `objective_value` | Objective value (worst-case comprehensive delivery cost) obtained in the run |
